# План и принятые решения

1. Зафиксировать исходные файлы и реальные номера уроков; создать конкретную карту A–O и проекты.
2. Реализовать локальную платформу на React, TypeScript и Vite: главная, карта, урок, проекты, отчёт.
3. Подготовить текущий подробный урок 9; будущие уроки пока содержат честно обозначенную карту, а не пустые конспекты.
4. Проверить типы, сборку, целостность карты, защиту прогресса, браузерные сценарии и сохранность источника.

Хранилище — localStorage одного браузера и origin. Регистрация, удалённый сервер и база не нужны. Структура данных имеет версию; импорт проверяется целиком перед заменой состояния. Перед импортом показывается сводка. Повреждённые данные не перезаписываются стартовым состоянием. Ошибки сохранения видны пользователю.

Статусы уроков отделены от четырёх уровней освоения и записей ревью. Новое прохождение требует чек-листа, доказательств и принятого самостоятельного решения. В локальном приложении ревью записывает человек: платформа не выдаёт самооценку за проверку преподавателем. Точка обучения —9; следующий урок открывается для изучения только после проверки9.

Интерфейс: тёмная тема Tokyo Night, спокойный синий/бирюзовый акцент, боковая навигация, читаемая колонка урока, настоящие формы с подписями, адаптивность и видимый фокус.

Зависимости приложения: React и React DOM. Инструменты разработки: TypeScript, Vite, плагин React, Playwright. Без отдельной библиотеки состояний, UI-комплектов или внешних шрифтов.
