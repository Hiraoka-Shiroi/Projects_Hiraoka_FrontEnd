# SafeCity Atyrau

Учебный прототип для хакатона: карта, заявления, графики и демонстрация отчётов в одном HTML-файле.

## Запуск

Откройте [SafeCity_Atyrau.html](SafeCity_Atyrau.html) в браузере. Для загрузки карт, графиков, шрифтов и встроенного видео нужен интернет. Установка Node.js и сборка не требуются.

Демонстрационные учётные записи:

| Роль | Логин | Пароль |
| --- | --- | --- |
| Администратор | `admin` | `admin123` |
| Сотрудник | `sotrudnik` | `sotrud123` |

## Что показывает прототип

- Данные, рекомендации и прогнозы заранее подготовлены для демонстрации интерфейса.
- При выборе файла используется только его имя. Содержимое не читается и не отправляется; кнопка показывает подготовленный пример отчёта.
- Камеры и уведомления показывают демонстрационный сценарий, а не подключение к городской системе видеонаблюдения.
- Вход работает в браузере без сервера. Это демонстрация ролей, не защищённая авторизация.
- Новые заявления и история отчётов хранятся в памяти текущей вкладки и исчезают после перезагрузки страницы.
