# Исходные материалы и реальная точка обучения

Дата создания: 12 октября 2026 года, часовой пояс Asia/Tashkent.

Источник только для чтения: `../Frontend`. Новая разработка: `frontend-academy`.
Обнаружены также соседние папки `Projects_Hiraoka_FrontEnd` и `test python`; они не используются для записи.

Прочитаны README и все девять файлов `Frontend/JavaScript`. Уроки 1–8 пройдены по сообщению ученика. Это история обучения, а не результат нового независимого экзамена. Уровень освоения в приложении сначала «не оценён»; для его повышения нужны доказательства.

Фактическая нумерация исходных файлов сохранена:

| № | Тема | История |
|---|---|---|
| 1 | Переменные | пройден |
| 2 | Арифметика | пройден |
| 3 | Типы данных | пройден |
| 4 | Условия if/else | пройден |
| 5 | Логические операторы | пройден |
| 6 | else if | пройден |
| 7 | Truthy и falsy | пройден |
| 8 | Тернарный оператор | пройден |
| 9 | Функции | в процессе, практика ещё не проверена |

В присланном описании темы 2 и 3 перечислены в обратном порядке. Выбраны номера существующих файлов, чтобы не менять историю.

Конспекты используют разделы с комментариями, отдельные примеры и практику. В исходном уроке 9 раздел практики пуст. Новый конспект дополняет объяснение `return`, значения `undefined`, раннего завершения и порядка аргументов; упражнения не содержат решений. Старые подробные конспекты не перенесены и не переписаны.

При дальнейшей проверке полезно коротко уточнить: `typeof` возвращает строки в нижнем регистре; выражение `typeof value` без вывода не печатает результат. В исходном файле урока 8 в конце есть Markdown-ограда из обратных кавычек, которая мешает запуску как JavaScript. Оригинал сохранён без исправлений. Эти наблюдения не отменяют ранее пройденные статусы.

До разработки сохранён SHA-256 всех 23 файлов источника в `original-files-before.json`. Итоговая проверка сравнивает относительные пути, размеры и SHA-256; она выявляет добавление, удаление и изменение содержимого файлов, включая скрытые файлы. Это проверка содержимого, а не всех метаданных файловой системы.
