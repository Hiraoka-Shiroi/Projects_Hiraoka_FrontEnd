Это урок по позициям

Цель: Закрепить понимание различных значений свойства position и их применение для создания различных макетов веб-страницы.

Свойство position в CSS используется для определения метода позиционирования элементов на веб-странице. Существует пять значений свойства position: static, relative, absolute, fixed и sticky

Значение static и relative

Элементы с position: static являются обычными элементами потока, они располагаются в соответствии с нормальным потоком документа. Является значением по умолчанию для всех элементов HTML.
Элементы с position: relative располагаются в обычном потоке документа, но можно использовать свойства top, right, bottom и left для их смещения относительно их нормального положения.

Значение absolute

Элементы с position: absolute позиционируются относительно ближайшего предка с position отличным от static. Если таких предков нет, элемент позиционируется относительно начального контейнера (обычно <body>).

Значение sticky

Элементы с position: sticky ведут себя как relative до тех пор, пока не достигнут заданной позиции при прокрутке, после чего ведут себя как fixed.
Элементы с position: fixed позиционируются относительно окна браузера и остаются на месте при прокрутке страницы.
